# Mod を共有する

Mod を作成したら、[Steam Workshop](https://steamcommunity.com/app/2079120/workshop/)にアップロードしてほかの人と共有できます。数クリックで完了します！

## チュートリアル

**Discover** タブに移動し、**Published Items → Create Item** をクリックします。

![](/doc-img/en-sharing-mod-1.png)

ポップアップウィンドウでアップロードフォームに入力します。

![](/doc-img/en-sharing-mod-2.png)

**Files** リストでは、**+** ボタンをクリックしてファイルを選択することで、アップロードするファイルを追加できます。

![](/doc-img/en-sharing-mod-3.png)

完了したら **OK** をクリックし、アップロードが終わるのを待つだけです。簡単ですね！
