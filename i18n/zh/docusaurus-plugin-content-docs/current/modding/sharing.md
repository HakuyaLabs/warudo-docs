# 分享你的 Mod

创建 Mod 后，你可以将它上传到我们的 [Steam 创意工坊](https://steamcommunity.com/app/2079120/workshop/) 与其他人分享。只需点击几下即可完成！

## 教程

前往 **Discover** 标签页，然后点击 **Published Items → Create Item**：

![](/doc-img/en-sharing-mod-1.png)

在弹出的窗口中填写上传表单：

![](/doc-img/en-sharing-mod-2.png)

在 **Files** 列表中，你可以点击 **+** 按钮并选择文件来添加要上传的文件。

![](/doc-img/en-sharing-mod-3.png)

完成后，只需点击 **OK** 并等待上传完成即可。很简单，对吧？
